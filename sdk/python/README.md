# kokonut-intelligence

Python SDK for the Kokonut Intelligence Platform. Typed REST client wrapping Directus collections for farm, crop, harvest, sales, expenses, sensors, attestations, and reports.

> The collection methods cover the Directus REST API. Optional generated gRPC
> stubs for the IRI, content hash, ecocredit, marketplace, and bridge services
> are packaged under `kokonut.grpc` and can be installed separately.

For the versioned native Gateway reads, use `KokonutPublicApiClient`. It is a
separate client because the Gateway and legacy Directus services have different
base URLs and contracts:

```python
from kokonut import KokonutPublicApiClient

api = KokonutPublicApiClient("http://localhost:8098")
locations = api.locations.list()  # bounded to the first 100 public locations
location = api.locations.get("location-uuid")
metrics = api.metrics.get("location-uuid")
assessment = api.crisp.get("location-uuid")
summary = api.analytics.get_summary("location-uuid")
api.close()
```

The v1 client covers public location list/detail, verified metric summaries,
published CRISP assessments, and governed location summaries. Writes, filters,
pagination, and private or authenticated fields are outside this contract. The
native endpoint schemas are generated by the Gateway's FastAPI OpenAPI document;
`docs/openapi.yaml` describes the separate Directus API. The scoped v1 contract
snapshot is in `docs/refactor/native-public-api-v1.openapi.json`.

## Install

```bash
pip install kokonut-intelligence
```

With optional dependencies:

```bash
pip install kokonut-intelligence[clickhouse]  # ClickHouse support
pip install kokonut-intelligence[web3]        # Web3 support
pip install kokonut-intelligence[grpc]        # Generated gRPC stub runtime
pip install kokonut-intelligence[all]         # All optional runtime integrations
```

The base installation does not install gRPC or Protocol Buffers. The `grpc`
extra adds only the runtime libraries needed to import and use the generated
stubs. To regenerate those stubs from the repository's authoritative `proto/`
sources, run these commands from a repository checkout:

```bash
python3 -m pip install -e 'sdk/python[grpc,grpc-codegen]'
python3 scripts/generate-python-sdk-protos.py
python3 scripts/generate-python-sdk-protos.py --check
```

Generated modules are available as `kokonut.grpc.common.pagination_pb2`,
`kokonut.grpc.data.v1`, and `kokonut.grpc.ecocredit.v1`. The protocol package
names, service names, and field definitions remain those declared in `proto/`.

## Usage

```python
from kokonut import KokonutClient

client = KokonutClient("http://localhost:8055", token="your-token")

# List locations
locations = client.locations.list()

# Get a farm by ID
farm = client.farms.get("farm-uuid")

# List crop cycles for a plot
cycles = client.crop_cycles.list_by_plot("plot-uuid")

# Create a harvest event
harvest = client.harvest_events.create({
    "crop_cycle_id": "cycle-uuid",
    "plot_id": "plot-uuid",
    "location_id": "location-uuid",
    "harvest_date": "2026-07-15",
    "quantity": 500,
    "unit": "kg",
    "status": "draft",
})

# Query unpaid sales
unpaid = client.sales_events.list_unpaid()

# Read governed carbon-credit ledger records for one location
credits = client.carbon_credits.list_by_location("location-uuid")
retirements = client.credit_retirements.list_by_location("location-uuid")
# Ledger helpers expose reads only; reviewed services own lifecycle changes.

# Aggregate query
counts = client.aggregate(
    "harvest_event",
    aggregate={"count": "*"},
    groupBy=["location_id"],
)
```

## Authentication

```python
# Login with email/password
client.login("user@example.com", "password")

# Logout
client.logout()
```

## Error Handling

```python
from kokonut import KokonutError, AuthenticationError, NotFoundError, ForbiddenError, ValidationError

try:
    client.locations.get("nonexistent")
except NotFoundError:
    print("Location not found")
except AuthenticationError:
    print("Please log in")
except ForbiddenError:
    print("Permission denied")
except ValidationError as e:
    print(f"Invalid input: {e}")
except KokonutError as e:
    print(f"API error {e.status_code}: {e}")
```

## Method Groups

| Group | Collection | Extra Methods |
|-------|-----------|---------------|
| `locations` | `location` | — |
| `farms` | `farm` | `list_by_location` |
| `plots` | `plot` | `list_by_farm` |
| `crop_cycles` | `crop_cycle` | `list_by_plot`, `list_active` |
| `harvest_events` | `harvest_event` | `list_by_crop_cycle` |
| `sales_events` | `sales_event` | `list_by_crop_cycle`, `list_unpaid` |
| `expense_events` | `expense_event` | `list_by_crop_cycle`, `list_pending_approval` |
| `sensor_readings` | `sensor_reading` | `list_by_device`, `list_by_plot`, `list_anomalies` |
| `wallet_profiles` | `wallet_profile` | `find_by_address` |
| `attestations` | `attestation_record` | `list_pending`, `list_by_entity` |
| `reports` | `report_snapshot` | `list_by_type` |
| `exports` | `export_log` | `create_export` |
| `noi` | `noi_snapshot` | `list_by_crop_cycle` |
| `carbon_credits` | `carbon_credit` | `list_by_location` |
| `credit_adjustments` | `credit_adjustment` | `list_by_location` |
| `credit_retirements` | `credit_retirement` | `list_by_location` |
| `credit_transfers` | `credit_transfer` | `list_by_location` |

Standard collection groups inherit `GenericMethods`: `list`, `get`, `create`,
`create_many`, `update`, `delete`. Credit-ledger groups are read-only and expose
only `list`, `get`, and `list_by_location`; governed lifecycle changes remain in
reviewed platform services.
