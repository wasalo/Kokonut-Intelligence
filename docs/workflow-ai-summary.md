# AI Summary Lifecycle

Spec: `ai_summary`

## Invariants

- An AI summary begins in draft, generated by an agent from approved governed data.
- Agent-generated summaries must be drafts; agents cannot publish.
- Verification requires a human reviewer.
- Publication makes the summary available for downstream consumers.
- Rejection is terminal and requires a reason.

## Decision Table

| ais_draft_entry | generator | draft | Generate AI summary | submit for review | submit | submitted | ais_submit | entry |
| ais_publish | system | published | Terminal published summary | - | terminal | - | - | terminal |
| ais_reject_draft | reviewer | rejected | Terminal rejected summary | - | terminal | - | - | terminal |
| ais_reject_submitted | reviewer | rejected | Terminal rejected summary | - | terminal | - | - | terminal |
| ais_reject_verified | reviewer | rejected | Terminal rejected summary | - | terminal | - | - | terminal |
| ais_submit | generator | submitted | Submit summary for review | rejected during review | reject | rejected | ais_reject_submitted | - |
| ais_submit | generator | submitted | Submit summary for review | reviewed and verified | verify | verified | ais_verify | - |
| ais_verify | reviewer | verified | Verify summary accuracy | approved for publication | publish | published | ais_publish | human-approval |
| ais_verify | reviewer | verified | Verify summary accuracy | rejected after verification | reject | rejected | ais_reject_verified | human-approval |
