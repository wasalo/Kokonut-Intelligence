# Report Snapshot Lifecycle

Spec: `report_snapshot`

## Invariants

- A report snapshot begins in draft, generated by the report generator.
- Report snapshots include public-interest context and uncertainty notes.
- Verification ensures data accuracy and completeness.
- Publication makes the report available for downstream consumers.
- Rejection is terminal and requires a reason.
