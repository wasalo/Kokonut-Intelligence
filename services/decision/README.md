# decision

`services.decision` — Decision policy engine — evaluates rules against oriented state.

## Modules

- `odds_engine` — Odds, posterior, and utility-based sequential decision calculations.
- `policies` — Decision policy definitions — default rules for the policy engine.
- `policy_engine` — Policy Engine — evaluates decision policies against situation assessments.
- `sequential_evidence` — Immutable evidence ledger primitives for sequential decisions.
- `sequential_integration` — Connect sequential posterior decisions to review tasks and solution gates.
