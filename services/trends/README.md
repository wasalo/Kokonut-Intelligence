# trends

`services.trends` — Trend Analysis — Statistical tools for time series pattern detection.

## Modules

- `accuracy` — Forecast Accuracy — MAE, RMSE, MAPE, bias tracking.
- `change_points` — Change-Point Detector — regime shift detection using CUSUM and PELT.
- `config` — Shared constants and configuration for trend analysis.
- `dashboard` — Trend Dashboard — precomputed trend metrics for dashboards and reporting.
- `decomposer` — Seasonal Decomposer — separates trend, seasonal, and residual components.
- `estimator` — Trend Estimator — least-squares fitting, slope, r-squared, correlation.
- `forecasting` — Time Series Forecaster — ARIMA models, prediction intervals, backtesting.
- `significance` — Trend Significance — Mann-Kendall test, confidence intervals, stationarity.
- `smoothing` — Time Series Smoothing — moving average, exponential smoothing, Holt's linear.
