# graph_projection

`services.graph_projection` — Governed, read-optimized graph projections.

## CLI Usage

```bash
python3 -m services.graph_projection
```
```bash
python3 -m services.graph_projection.cli --help
```

## Modules

- `cli` — Graph projection command line interface.
- `evidence_lineage` — Explicit source adapters for the evidence-lineage projection.
- `kernel` — Atomic full-rebuild projection kernel.
- `policy` — Publication policy for projected records.
- `query` — Bounded reads against the active graph generation.
