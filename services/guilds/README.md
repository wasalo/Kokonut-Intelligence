# guilds

`services.guilds` — Kokonut Guild protocol services.

## CLI Usage

```bash
python3 -m services.guilds.cli --help
```

## Modules

- `cli` — CLI for canonical Guild reputation and Moloch observation helpers.
- `indexer` — Self-hosted KGP event indexer for Gnosis and Chiado.
- `kgp` — Canonical KGP identity, voucher, and projection helpers.
- `moloch` — Read-only integration helpers for the Kokonut Moloch DAO on Gnosis.
- `projections` — Database projection helpers for Guild protocol events.
- `reputation` — Canonical PostgreSQL-to-KGP reputation event creation.
