# strategy_markup

`services.strategy_markup` — Machine-readable strategy projections.

## CLI Usage

```bash
python3 -m services.strategy_markup
```

## Modules

- `exporter` — Deterministic StratML Part 1 projection for governed strategy plans.
- `ids` — Stable identifiers used by normalized strategy projections.
- `mapping` — Map canonical PostgreSQL rows into the normalized strategy model.
- `model` — Typed normalized strategy representation used by all projections.
- `validator` — Semantic and structural validation for normalized strategy documents.
