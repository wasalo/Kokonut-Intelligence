# finance

`services.finance` — Finance module: financial statements, IRR/NPV, investment analysis.

## CLI Usage

```bash
python3 -m services.finance.cli --help
```

## Modules

- `cli` — Finance CLI: Financial statements and investment analysis.
- `financial_statements` — Financial Statement Formatter: Income Statement, Balance Sheet, Cash Flow Statement.
- `models` — Finance models: dataclasses for financial analysis.
- `return_calculator` — IRR/NPV Calculator: Internal Rate of Return, Net Present Value, Modified IRR.
