# systems

`services.systems` — Systems Thinking — Causal loops, leverage points, archetypes, simulation, and adaptation acceleration.

## CLI Usage

```bash
python3 -m services.systems.cli --help
```

## Modules

- `archetypes` — System Archetype Detector — identifies common systemic traps in farm data.
- `causal_loops` — Causal Loop Diagram Engine — defines reinforcing/balancing feedback structures.
- `cli` — Systems-thinking CLI — help-only stub.
- `config` — Shared constants, loop definitions, and configuration for systems thinking.
- `delays` — Time-Delay Mapper — tracks action-to-effect delays in farm systems.
- `double_loop` — Double-Loop Learning Controller — questions underlying structure.
- `growth_curve` — Growth Curve Analyzer — detects exponential growth, S-curves, and tipping points.
- `improvement_tracker` — Improvement Rate Tracker — tracks whether metrics are getting better over time.
- `leverage` — Leverage Point Analyzer — maps Meadows' 12 leverage points to farm context.
- `mental_models` — Mental Model Elicitor — captures and compares stakeholder worldviews.
- `meta_learning` — Meta-Learning Layer — learns which adaptation strategies work best.
- `ml_retraining` — ML Retraining Pipeline — scheduled retraining based on model performance degradation.
- `process_control` — Statistical process control over process KPIs (BPM Optimize phase).
- `stock_flow` — Stock-and-Flow Simulator — dynamic system modeling with PySD.
- `velocity_tracker` — Adaptation Velocity Tracker — measures whether the system is getting faster at learning.
