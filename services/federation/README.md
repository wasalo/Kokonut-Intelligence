# federation

`services.federation` — Inter-farm federation protocol.

## CLI Usage

```bash
python3 -m services.federation.cli --help
```

## Modules

- `cli` — CLI for federation protocol.
- `node` — Federation node management — register, sync, heartbeat.
- `protocol` — Federation protocol — share data and query across farm nodes.
- `sync` — Federation sync engine — incremental data exchange between nodes.
