# sandbox

`services.sandbox` — Sandboxed analysis environments for safe computation.

## CLI Usage

```bash
python3 -m services.sandbox.cli --help
```

## Modules

- `cli` — CLI for sandboxed analysis environments.
- `environment` — Analysis environment — create, destroy, and run computations in isolated contexts.
- `isolation` — Isolation guard — SQL-level isolation for sandboxed analysis.
- `monitor` — Resource monitor — tracks CPU, memory, and DB usage for sandbox runs.
