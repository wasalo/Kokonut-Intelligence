# data_stream

`services.data_stream` — Data Stream: Chronological project data posts for environmental project tracking.

## CLI Usage

```bash
python3 -m services.data_stream.cli --help
```

## Modules

- `anchor` — Blockchain anchoring for data stream posts via EAS.
- `cli` — CLI for data stream operations.
- `files` — Data Stream File management: structured file metadata for posts.
- `post` — Core CRUD operations for data stream posts.
- `stream` — Chronological stream queries for data stream posts.
