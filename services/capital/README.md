# capital

`services.capital` — Capital accounting module (Keynes-inspired, constructive only).

## CLI Usage

```bash
python3 -m services.capital.cli --help
```

## Modules

- `accounting_report` — Composite capital-accounting report builder (advisory).
- `capacity` — Output-capacity & national-income analog for the 8 Forms of Capital.
- `capture` — Value-leakage / capture-risk signal for the 8 Forms of Capital.
- `cli` — Capital accounting CLI (Keynes-inspired, constructive only).
- `credit` — Deferred regenerative credit ledger (Keynes deferred-pay analog).
- `diversion` — Consumption-vs-production diversion index for the 8 Forms of Capital.
