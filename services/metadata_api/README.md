# metadata_api

`services.metadata_api` — Metadata Graph API: IRI resolution, JSON-LD, and linked data services.

## CLI Usage

```bash
python3 -m services.metadata_api.cli --help
```

## Modules

- `anchor` — Anchored metadata: on-chain anchoring for metadata IRIs.
- `app` — FastAPI Metadata Graph API.
- `app_metadata` — Application-level metadata: additional off-chain project info.
- `cli` — CLI for Metadata Graph API.
- `project_info` — ProjectInfo: Complete project view aligned with Regen Framework WG ProjectInfo schema.
- `resolver` — Metadata resolution and JSON-LD serialization.
