# agents

`services.agents` — Agent metadata helpers for Kokonut Intelligence.

## CLI Usage

```bash
python3 -m services.agents
```
```bash
python3 -m services.agents.cli --help
```

## Modules

- `ai_summary` — AI Summary Generator — Agent-generated narratives for locations
- `bio_factory_agent` — Bio-organic fertilizer operations synthesis agent for Latin America and the Caribbean.
- `capital_efficiency_agent` — Capital efficiency and utility synthesis agent.
- `cids_agent` — CIDS export agent.
- `cli` — Agent task catalogue CLI — lists available agent tasks and their schemas.
- `commons_agent` — Commons liberation and stewardship synthesis agent.
- `delphi_facilitator_agent` — Delphi facilitator agent.
- `ebf_calibration_agent` — EBF calibration memo agent.
- `ebf_evidence_gap_agent` — EBF evidence gap agent.
- `ebf_scorecard_agent` — EBF scorecard draft agent.
- `ecological_modeling_agent` — Signed-worker ecological modeling synthesis: ecological interaction, energy flow, pest, soil input, resource, biodiversity, livestock feed, and reward calibration data.
- `feedback_agent` — Stakeholder feedback synthesis agent.
- `gnh_agent` — Gross National Happiness alignment synthesis agent.
- `kokonut_commons_agent` — Kokonut commons governance synthesis agent.
- `logging` — Agent Action Logging
- `manifest` — Capability manifest helpers for Kokonut Agentic Marketplace metadata.
- `open_source_capitalist_agent` — Open Source Capitalist scaling economics synthesis agent.
- `organic_readiness_agent` — Organic readiness synthesis registered with the signed worker; its legacy analytics resolve only through narrow, signed location views.
- `regenerator_agent` — Regenerative outcomes and stewardship synthesis agent.
- `resilience_agent` — Financial resilience and scaling synthesis agent.
- `safety` — Agent safety helpers for bounded write and audit behavior.
- `tasks` — Agent task catalogue and output schema helpers.
- `wellbeing_agent` — Holistic well-being synthesis agent.
