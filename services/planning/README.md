# planning

`services.planning` — Enterprise planning domain: budgeting, performance, portfolio, S&OP.

## CLI Usage

```bash
python3 -m services.planning
```
```bash
python3 -m services.planning.cli --help
```

## Modules

- `budget` — Financial planning / budgeting service (FP&A).
- `capacity_aware` — Capacity-aware planning projections.
- `cli` — Enterprise planning CLI: financial plans and budgets (FP&A).
- `model` — Shared helpers for governed enterprise-planning entities.
- `performance` — Performance management (Balanced Scorecard / MbO) service.
- `portfolio` — Program / project portfolio (PPM) service.
- `sandop` — Sales & Operations Planning (S&OP) cockpit (read-only).
- `strategy_allocation` — Composite strategic investment scoring and allocation decisions.
