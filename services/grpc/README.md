# grpc

`services.grpc` — gRPC server for Kokonut Intelligence.

## CLI Usage

```bash
python3 -m services.grpc.cli --help
```

## Modules

- `auth` — API key authentication interceptor for gRPC.
- `cli` — CLI for gRPC server.
- `credit_class_service` — Ecocredit gRPC service implementation.
- `data_service` — Data module gRPC service implementation.
- `health` — gRPC health check service.
- `interceptors` — gRPC logging interceptor.
- `server` — gRPC server entry point for Kokonut Intelligence.
