# crisp

`services.crisp` — CRISP risk scoring engine — internal farm risk intelligence.

## CLI Usage

```bash
python3 -m services.crisp
```
```bash
python3 -m services.crisp.cli --help
```

## Modules

- `carbon_yield` — Carbon yield risk scoring module.
- `cli` — CRISP Risk Scoring CLI
- `climate_risk` — Climate catastrophe risk scoring module.
- `config` — CRISP scoring configuration.
- `financial_risk` — Financial viability risk scoring module.
- `implementation_risk` — Implementation risk scoring module.
- `models` — CRISP risk scoring data models.
- `normalization` — Normalization helpers for CRISP 0-100 risk scores.
- `policy_risk` — Policy and legal risk scoring module.
- `scoring_engine` — CRISP scoring engine — composite aggregation and rating.
