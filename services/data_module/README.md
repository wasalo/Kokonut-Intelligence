# data_module

`services.data_module` — Data Module v2: Rich content hashes, resolvers, attestors.

## CLI Usage

```bash
python3 -m services.data_module.cli --help
```

## Modules

- `attestor` — Data Attestor: per-IRI attestor tracking.
- `cli` — CLI for Data Module v2 operations.
- `content_hash` — Content Hash: structured content hash with type, algorithm, media type.
- `resolver` — Data Resolver: resolver registry and data-resolver registration.
